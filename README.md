# 📝 Meeting Analysis

**Meeting Analysis** is a web-based application designed to analyze meeting conversations, organize discussion points, and extract important information. The system helps users identify key topics, summarize meeting notes, highlight action items, and track decisions to improve meeting productivity.

## 🚀 Features

- 🎤 Meeting audio transcription
- 📝 Upload or enter meeting notes
- 📌 Extract important discussion points
- 📋 Generate meeting summaries
- ✅ Identify action items and tasks
- 👥 Record participants and responsibilities
- 🔍 Extract keywords and topics
- 📊 Display meeting statistics
- 💾 Save and manage meeting records

## 🛠️ Technologies Used

- **HTML5** – Webpage structure
- **CSS3** – Styling and responsive design
- **JavaScript** – Application logic
- **Web Speech API** – Speech recognition where supported
- **Chart.js** – Data visualization
- **LocalStorage** – Store meeting notes in the browser

## ⚙️ How It Works

1. The user enters meeting notes or provides a transcript.
2. The application processes the meeting content.
3. Important topics and keywords are identified.
4. Key points, decisions, and action items are organized.
5. A meeting summary is displayed for review and storage.

## 🎯 Objective

The main objective of this project is to simplify meeting documentation, reduce manual note-taking, and help teams track important decisions and follow-up tasks efficiently.

## 🌍 Applications
